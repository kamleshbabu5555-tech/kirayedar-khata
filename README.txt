KIRAYEDAR KHATA - APK BANANE KE STEPS (free, GitHub se)

Is folder mein ye files hain:
  index.html, jspdf.umd.min.js, package.json, capacitor.config.json,
  icon-only.png, icon-foreground.png, icon-background.png,
  .github/workflows/build-apk.yml

1) github.com par free account banayein aur login karein.
2) "New repository" dabayein. Naam: kirayedar-khata. "Create repository" dabayein.
3) Repository ke andar "uploading an existing file" (ya Add file > Upload files) dabayein.
   Ye 7 files select karke upload karein (.github folder abhi nahi):
     index.html, jspdf.umd.min.js, package.json, capacitor.config.json,
     icon-only.png, icon-foreground.png, icon-background.png
   Neeche "Commit changes" dabayein.
4) Ab Add file > Create new file dabayein. Naam ki jagah ye likhein (slash ke saath):
     .github/workflows/build-apk.yml
   Phir build-apk.yml file ka poora text copy karke yahan paste karein. "Commit changes" dabayein.
   (Computer par ho to .github folder seedha upload bhi kar sakte hain.)
5) Upar "Actions" tab kholein. "APK banao" chalta dikhega. 5 se 10 minute lagte hain.
   Hara tick aa jaye to build poora hua. Agar kuch na chale to "Run workflow" dabayein.
6) APK lene ke liye repository ke main page par daayein taraf "Releases" kholein.
   Wahan "Kirayedar-Khata.apk" download karein.
7) Phone mein APK kholein. Android "unknown source se install" ki permission maangega,
   usse allow karein. "Play Protect" chetawani aaye to "Install anyway" dabayein.

DHYAN RAKHEIN
- Data sirf phone ke andar rehta hai. App uninstall karne par data hat jata hai.
  App ke andar Backup / restore se text copy karke rakhein.
- Purane web version ka data lana ho to wahan Backup text copy karein
  aur naye app mein Backup / restore mein paste karke Restore karein.
- Ye debug APK hai: Play Store par daalne ke liye nahi, sirf apne phone ke liye.
